# Polices du projet

Pour activer le chargement intégré des polices pédagogiques dans l’application web, placer ici les fichiers suivants :

- Marelle2-Regular.ttf (ou .otf / .woff2)
- MarelleBaton2-Regular.ttf (ou .otf / .woff2)

Marelle n'est pas incluse : le lien de téléchargement est indiqué dans le README principal.

OpenDyslexic est déjà incluse (`OpenDyslexic-Regular.woff2`, `OpenDyslexic-Bold.woff2`),
sous licence SIL Open Font License 1.1 (voir `OpenDyslexic-LICENSE.txt`).
