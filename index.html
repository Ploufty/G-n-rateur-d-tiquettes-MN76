Aide rapide

Paramètres : la roue crantée permet de personnaliser la position du ruban, son style ou de réinitialiser l’outil.

Onglet Texte : les mots sont saisis dans l’onglet Texte. Le bouton Créer les étiquettes génère ensuite les étiquettes. Plusieurs choix sont disponibles : découpage, police, style, couleurs et forme des étiquettes.

Déplacement : une étiquette se déplace avec la souris, le doigt ou le stylet.

Suppression : une étiquette déposée dans la corbeille, en bas à gauche, est supprimée. Il est aussi possible de vider l’ensemble des étiquettes depuis l’onglet Accueil.

Onglet Images : l’onglet Images permet d’ajouter une ou plusieurs images en une seule sélection. Les images générées peuvent être redimensionnées à l’aide de la poignée située dans l’angle inférieur droit de l’étiquette.

Onglet Colonnes : pour les tâches de tri ou de catégorisation, des colonnes peuvent être générées en fond. Elles sont personnalisables, peuvent être supprimées individuellement, ou toutes supprimées depuis l’onglet Accueil avec Vider les colonnes.

Sauvegarde : l’onglet Accueil permet d’enregistrer ou d’ouvrir une activité au format .etiq.

Installer les polices utilisées

Certaines polices proposées dans l’application doivent être disponibles pour être utilisées correctement. Elles peuvent être intégrées au projet dans le dossier assets/fonts, ou installées directement sur l’ordinateur.

Polices utilisées dans ce projet :

  • Marelle 2 : écriture cursive.
    Nom exact du fichier attendu : Marelle2-Regular.ttf
  • Marelle Baton 2 : cursive, majuscules en capitales.
    Nom exact du fichier attendu : MarelleBaton2-Regular.ttf
  • OpenDyslexic : police adaptée à certains besoins de lisibilité.
    Nom exact du fichier attendu : OpenDyslexic-Regular.otf

Pas à pas conseillé :

  1. Vous téléchargez la police souhaitée depuis son site officiel :
    Marelle 2 et Marelle Baton 2 : https://marelle.forge.apps.education.fr/#telecharger
    OpenDyslexic : https://opendyslexic.org/
  2. Vous ouvrez le fichier de police téléchargé, puis vous le décompressez si nécessaire.
  3. Pour une intégration directe dans le projet web, vous placez les fichiers de police dans le dossier assets/fonts avec les noms exacts suivants :
    • Marelle2-Regular.ttf
    • MarelleBaton2-Regular.ttf
    • OpenDyslexic-Regular.otf
  4. Pour une installation sur Windows, deux solutions sont possibles :
    • placer ou glisser les fichiers de police dans le dossier C:\Windows\Fonts ;
    • ou faire un clic droit sur le fichier de police, puis choisir Installer pour tous les utilisateurs.
  5. Vous redémarrez le navigateur si la police n’apparaît pas immédiatement dans l’application.

Si une police n’est pas présente dans le projet et n’est pas installée sur l’ordinateur, le navigateur utilise automatiquement une police de secours.
